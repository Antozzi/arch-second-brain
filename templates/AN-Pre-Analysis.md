- [ ] Назначен спонсор инициативы и ключевые стейкхолдеры
- [ ] Зафиксированы их ожидания и ограничения
- [ ] Сформулировано Problem Statement (что, для кого, зачем)
- [ ] Определены границы и допущения (in/out of scope, зависимости)
- [ ] Рассмотрены 2–3 альтернативы; выбран рекомендуемый вариант
- [ ] Подготовлена эскизная схема (Business Context + Integration viewpoints)
- [ ] Описаны основные интеграционные точки, протоколы, аутентификация
- [ ] Определены ключевые NFR с целевыми диапазонами
- [ ] Описан Value Proposition
- [ ] Определены 5–7 измеримых KPI
- [ ] Зафиксированы топ-3 риска с мерами снижения
- [ ] Review Outcome = Pass или Pass with comments
- [ ] Pre-Analysis согласован с Initiative Owner
