# Release Notes

## MortalCombat1 — 2026-05-20

Крупный релиз: генерация диаграмм и шаблонов, кросс-платформенность,
полнопокрытийная обработка документов.

### Диаграммы

- **PlantUML** — новый режим в **◈ Генерация артефакта**: модель строит диаграмму
  из базы знаний (sequence, component, C4, deployment, activity, ER, state, class,
  mindmap, gantt, wbs и др.), живое превью, экспорт в SVG. Рендер локальный через
  `plantuml.jar` + Java.
- **drawio** — режим генерации валидного `mxGraphModel` XML из знаний: редактируемый
  код + превью офлайн-вьюером, экспорт `.drawio`, сохранение в проект.
- **Импорт .drawio** — существующая диаграмма разбирается в **каталог объектов
  проекта** (`diagram-objects.json`); объекты переиспользуются в новых диаграммах
  для согласованности. Содержимое уходит в базу знаний через обычный пайплайн.
- Сжатый формат `.drawio` (deflate) распаковывается автоматически при ingest.

### Шаблоны артефактов

- Новый раздел меню **◇ Шаблоны** — библиотека шаблонов, просмотр, удаление.
- Генерация `.md` шаблона **из документа** — модель извлекает структуру разделов
  из конвертированного raw-документа проекта.
- Генерация шаблона **из ИТ-стандарта** — TOGAF, ISO 42010/25010, BABOK, PMBOK:
  каноничная структура артефакта.

### Обработка документов

- **Чанкинг с полным покрытием** — большие документы больше не обрезаются по
  `MAX_CHARS`: файл режется на чанки, каждый идёт через модель, результаты
  сливаются с дедупликацией ID. Ничего не теряется.
- **Кириллица + qwen** — система определяет долю кириллицы в `/raw` и предлагает
  установить модель `qwen2.5` (точнее с русским). Установка одним кликом из потока
  Ingest или вопросом в deployment-визарде. Эндпоинты `/api/cyrillic-check`,
  `/api/ollama-pull`.

### Кросс-платформенность

- Единый репозиторий для macOS, Linux и Windows. Точка входа: `start.sh`
  (macOS/Linux) и `start.bat` (Windows).
- Deployment-визард в обоих скриптах: проверка Node/Ollama/PlantUML/.env,
  авто-скачивание `plantuml.jar`, вопрос про русскоязычные документы.
- `server.js` — Windows PATH и `taskkill`; `process.sh` — определение ОЗУ для
  Windows/MSYS.
- Новый документ **DEPLOYMENT.md** — запуск, тестовый прогон, логи, диагностика.

### Исправления

  останавливалась только обёртка `sh`, а скрипт продолжал работать).
