☁ Confluence / Jira
Серверы и токены для загрузки проектов по ссылке. Схема авторизации определяется автоматически: Bearer (Personal Access Token) либо Basic (email + токен — для Cloud и плагинов API-ключей на on-prem). Укажи email, если используешь Basic-токен. Токены хранятся локально в .env.
Для Cloud укажи адрес с /wiki в конце.
🔒 Деперсонализация
Корпоративные данные (имена сотрудников, названия систем и компонент инфраструктуры) остаются только в локальной базе знаний. При включённой деперсонализации они заменяются обезличенными плейсхолдерами в каждом запросе к облачному Claude API — для безопасной работы с третьими лицами. Локальная модель (Ollama) и raw-материалы облака не касаются.
Замена регистронезависимая. Длинные значения применяются раньше коротких.
